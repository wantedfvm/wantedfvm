# Olá, sou o Lucas 👋

Software Engineer em início de carreira, de Porto Alegre. Curso Engenharia de Software (Estácio) e construo aplicações web com TypeScript, React e Next.js. Já coloquei um produto no ar sozinho.

### O que construí

- **[Rosa Caixa](https://github.com/wantedfvm/rosa-caixa)**: controle de caixa para autônomos, em produção em [controle.rosanetwork.cloud](https://controle.rosanetwork.cloud). Next.js 15, Drizzle, Turso, Better Auth e testes automatizados.
- **[Collab-Board](https://github.com/wantedfvm/collab-board)**: quadro branco colaborativo em tempo real, com Liveblocks e Fabric.js.
- **[Aero Tracker](https://github.com/wantedfvm/aero-tracker)**: Kanban local-first com IndexedDB e dnd-kit.

### Stack

TypeScript · React · Next.js · Node.js · Tailwind · SQL (SQLite/Turso) · Drizzle · Git e GitHub Actions
